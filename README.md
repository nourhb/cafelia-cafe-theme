# Cafelia — Café & Coffee House WordPress Theme

A warm Full Site Editing (block) theme for cafés and coffee houses.

## Design

- Espresso brown (`#3e2f25`) + cream (`#f5efe6`) with caramel (`#c68b4e`) accent
- Welcoming hero with opening-hours badge
- Drinks & food menus with prices
- Barista team, events, catering CTA
- Inter typeface (bundled, OFL licensed)
- "Midnight" and "Garden" style variations included

## Templates

| Template | Purpose |
|---|---|
| `front-page.html` | Hero, info bar, story, menus, stats, gallery, testimonials, events, catering CTA, newsletter |
| `page-menu.html` | Drinks + food menus |
| `page-about.html` | Story, barista team, stats |
| `page-events.html` | Events listing |
| `page-catering.html` | Catering CTA + testimonials |
| `page-contact.html` | Contact info cards |
| `page.html` / `page-wide.html` | Standard and wide page layouts |
| `single.html`, `archive.html`, `search.html`, `index.html`, `404.html` | Blog and utility templates |
